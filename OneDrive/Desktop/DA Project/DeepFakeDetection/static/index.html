What is a Deepfake?

A deepfake is synthetic digital media where a person's facial features, expressions, or head movements are modified or completely synthesized using deep generative models (such as Generative Adversarial Networks, Autoencoders, and Latent Diffusion models). While synthetic media offers creative use cases in animation, it also creates risks of media forgery and digital impersonation.

Project Overview

This project uses computer vision and deep learning techniques to analyze images and videos for patterns associated with manipulated facial content. By evaluating high-frequency boundary discrepancies, spatial gradient inconsistencies, and temporal jitter across video frames, the system provides automated assessments with a 3-tier classification framework (Likely Authentic, Potential Deepfake, and Inconclusive).

Technologies Used
Python 3.14 PyTorch OpenCV FastAPI SQLite HTML5 / CSS3 / JavaScript (ES6) Printable PDF Report NumPy & Pillow
Detection Modes & Workflow

The model is primarily designed for Video Multi-Frame Analysis where temporal landmark continuity can be verified across time. Single images are analyzed using Single-Image Spatial Assessment (spatial frequency & boundary inspection).

Step 1

Upload

Image/Video validation & metadata extraction.

Step 2

Face Localization

Facial boundary & landmark region isolation.

Step 3

Prediction

Artifact scoring & Grad-CAM map generation.

Step 4

Report

Reliability calculation & analysis summary.

System Limitations & Scope
  • Detection accuracy depends significantly on source media resolution, lighting conditions, and compression history.
  • Single-image detection is inherently less reliable than multi-frame video assessment because temporal consistency cues cannot be analyzed.
  • Heavily compressed or social-media re-encoded media (e.g. WhatsApp/Instagram) may introduce compression noise that obscures subtle high-frequency boundaries.
  • Uncertain predictions are classified as Inconclusive to prevent overconfident false alarms on unconstrained real-world camera photos.
